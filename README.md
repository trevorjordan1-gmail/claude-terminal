# claude-terminal has moved

**claude-terminal is now Ai Terminal:** <https://github.com/adnettech/ai-terminal>

```bash
curl -fsSL https://get.adnet.tools | bash
```

This repository only forwards old links: `get.sh`, `bootstrap.sh` and the Windows
scripts here hand over to the new kit (an old `~/claude-terminal` checkout is moved aside
and kept). Cloud/DCV fleet terminals that still follow this URL install their kit from
their own release channel instead.
